# Proxy Checker v6.6.2 — 大批量结果性能优化

## 本次更新

1. **摘要优先、结果分页**：先显示真实任务进度，再按每页最多 1000 条恢复结果。任务完成、停止或失败后的尾页保留 15 分钟；任务切换时丢弃旧请求。
2. **历史增量同步**：只上传新增检测记录，失败重试；服务器加锁幂等追加，重复数据不重写文件；清空与未完成上传串行执行。
3. **异步缓存**：使用 IndexedDB 保存结果，5 秒窗口合并写入，自动迁移旧快照；保护清空和迟到读取，缓存不可用时采用有界降级。
4. **局部列表更新**：有效、失效和仓库列表复用未变化的节点，保留详情展开状态，继续限制首屏行数。

同时修复逐条全表扫描造成的平方级合并开销，以及加载前误显示“自动未开启”、状态请求失败后停止刷新等问题。

## 验证

- 本地回放中，4000 条结果处理由约 5.3 秒降至约 0.04 秒；23575 条约 0.15 秒，50163 条约 0.31 秒。此数据不含网络传输和真实浏览器绘制时间。
- 50000 条合成结果的轻量摘要约 1 KB；每页最多 1000 条。
- 新增 HTTP 分页、终态尾页、任务切换、增量同步、缓存竞态与 DOM 节点复用回归。
- 镜像发布继续受前后端回归、双身份模式完整冒烟及真实容器测试约束。

## 升级

镜像：`ghcr.io/fujunchao/proxy-checker:v6.6.2`（另同步 `latest`，支持 amd64 / arm64）。

更新镜像后重新创建容器，继续挂载原数据卷并保留原环境配置；浏览器强制刷新以加载新前端。无需修改已有订阅链接或迁移服务器仓库数据。此版本不改变代理检测判定或入库策略，也不把之前的 502 网关故障归因于前端。

详见 [实施计划](https://github.com/fujunchao/proxy-checker/blob/v6.6.2/docs/implementation-plan-v6.6.2.md)。
